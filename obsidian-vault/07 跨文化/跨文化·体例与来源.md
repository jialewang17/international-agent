# 跨文化·体例与来源

> 本页说明这份子库的数据从哪里来、引用怎么处理、命名与重跑规则。

## 一、三个数据来源

| 来源 | 位置 | 用途 | 关系 |
|---|---|---|---|
| 《The Culture Map》(Erin Meyer, 2014) | 无电子版；依原书章节结构与作者公开的八量表说明整理 | 理论编的八张量表与对照编的刻度定义 | **不逐字复制**，只做要点归类 |
| 文化地图子库 | `06 文化地图/` | 量表要点、原书小节、国家位置 | **只读复用**，生成时从 `cmap_build/data/` 读取 |
| 母库标注视图 | vault 根目录 `对外交流·*.md` | 实践编的七类条目 | **只读**，由母库 `_build_vault.py` 生成 |

## 二、数据流

```
母库 data/*.js
   └─ _gen_external.py ─> data/external.js
                            └─ _build_vault.py ─> 对外交流·*.md   （根目录，只读）
                                                        │
文化地图 06 文化地图/ ── cmap_build/data/ ──────────────┤
                                                        ▼
                                          xcul_build/build.py
                                                        │
                                                        ▼
                                            07 跨文化/  +  跨文化总览.html
```

**关键约定：本库不改母库、不改 06 文化地图。** 母库重跑后，重跑本库生成器即可重新同步实践编的条目清单；理论编的量表要点也会跟着 `cmap_build` 更新。

## 三、引用与版权

- 《The Culture Map》部分：**只做逐节的内容归类与要点整理，不逐字复制全文**。摘句仅取短句并注明来源章节；国家位置标注为「原书图表大致读数」。
- 母库条目部分：条目本身由你维护，本库只引用链接，不搬运正文。
- 如果日后补入原书电子版，可按页补充原句与页码——把 PDF 放进 vault 说一声即可。

## 四、命名与结构

- 全部笔记以 `跨文化` 为前缀（`跨文化理论·…`、`跨文化交流·…`、`跨文化对照·…`），与母库 1000+ 篇笔记**不重名**。
- 三级结构：**编（01/02/03 目录）→ 篇（MOC 或章节）→ 条目链接（指向母库）**。
- 对照编是唯一的内容增量：其余两编都是组织与浓缩。

## 五、重跑

```
python xcul_build/build.py
```

会先清空 `07 跨文化/` 下的全部 .md，再按 `data/x1_theory.py`、`x2_exchange.py`、`x3_bridge.py`、`x4_meta.py` 重建，同时刷新工作区的 `跨文化总览.html`。**不改动 `05 泉州/`、`06 文化地图/` 与母库根目录的任何文件。**

想改内容：改对应的 data 文件再重跑。想改对照编的解读，改 `x3_bridge.py`。
