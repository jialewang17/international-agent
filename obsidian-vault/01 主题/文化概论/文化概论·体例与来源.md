# 文化概论·体例与来源

> 数据来源、层级约定、重跑方式。

## 一、来源

- 原书：张岱年、方克立主编《中国文化概论》（北京师范大学出版社）。本次依用户提供的目录截图（第五～十一章，上编末章＋中编全部）建库；其余章节（绪论、第一～四章、第十二～十九章）可随时按同一体例补充。
- 正文为**要点整理**：内容为该书论述范围的公共知识概述，不逐字复制原书；如需原文与页码，把电子版放进库即可按节补齐。
- 「库内关联」把书中小节与母库既有条目互链：如「唐诗宋词」↔ `01 主题/文学` 的唐诗宋词条目，「中医药学」↔ `01 主题/医药`，「四大发明·造纸术」↔ [[宣纸传统制作技艺]]，「中外文化第二次大交汇」↔ [[对外交流·外来传入]]。

## 二、层级约定（严格三级）

| 层级 | 对应 | 形态 |
|---|---|---|
| 一级标题 | 章 | 文件夹「第五章 …」＋ 章 MOC（`文化概论·第五章`） |
| 二级标题 | 节 | 文件夹「第一节 …」＋ 节 MOC（`文化概论·五章一节`） |
| 三级标题 | 小节 | 内容笔记（`文化概论·<小节名>`），**正文所在** |

即：**章 → 节 → 小节 → 正文**，等价于「饮食 → 鲁菜 → 鲁菜的菜品内容」。
