# ChinaStory Post & News v3.1｜验收测试矩阵

> 这些是测试规范与伪造的**合成输入材料**，不是已经调用 Qwen/ChatGPT 执行过的实验结果；任何测试中的“机构、事件、人物”若未提供具体来源，都不能被作为真实新闻事实使用。

## 1. 测试字段

每例应记录：`case_id`, `input_evidence_ids`, `genre`, `format`, `target_platform`, `expected_behavior`, `hard_fail_condition`, `generation_skill_version`, `model_id`, `evaluation_rubric_version`。

## 3. News

## 4. 测试执行建议

1. **先做静态测试**：Markdown 结构、链接、字段名存在性、版本号及 source ID 引用完整性。
2. **再做确定性检查**：平台长度由程序校验；JSON 由 Schema 校验；证据 ID 必须在 EvidencePack 中存在。
3. **再做真实模型测试**：每个主题用固定输入与模型参数分别运行 v2.1、v3.1，保存结果与模型版本。
4. **最后由 Evaluation Skill 评 D1–D6**，并安排真人评审；由 Part 1 独立核验事实。模型评价不是事实的最终裁决。
5. **记录对照效果**：过硬约束率、跨文化理解度、独立编辑通过率、生成成本与延迟；未进行真实测试之前不声称 v3.1 显著改进。
