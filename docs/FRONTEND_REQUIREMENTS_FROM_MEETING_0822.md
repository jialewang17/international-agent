## 一、前端必须补的核心能力（老师点名）

### 1. 【P0】用户上传资料 → 再生成（当前最大缺口）

老师原意（预定会议约 36:00）：

> 逻辑里可能是：我有一个需求，**上传一些资料**，让他帮我主动生成帖子或内容；  
> 你现在**没有上传界面**——不是只给一个主题就自由发挥；  
> 实际工作中（如张铁机车）一定会收到资料，应把资料喂给 AI，**不完全靠自己瞎编**。

| 要求项 | 说明 |
|--------|------|
| 上传入口 | 前端要有「上传资料」区域（文件 / 粘贴文本 / 可选链接） |
| 生成逻辑 | 成稿时 **用户资料 + 本地库** 一起作为论据来源，不是只靠本地库 |
| 可见性 | 论据面板应能区分：`本地库` / `用户上传` |
| 约束 | 可核验事实仍须有据；上传材料进入 `evidence_used`，避免模型用常识偷补 |

**与现工作台差距**：现有 Composer 只有主题/国家/平台等参数，**无上传**。

### 2. 【P0】产出类型可扩展（先贴文，再多体裁）

老师原意（约 28:22）：

> 贴文正文可以有更多类型：贴文、新闻稿、专题深度稿、短视频脚本……  
> 可以一点点加，**先把贴文做好**。

| 阶段 | 前端表现 |
|------|----------|
| 现在 | 主动发帖 / 选题 / 评论回复（已有雏形） |
| 下一步 | 输出类型下拉：`社交帖文` \| `新闻稿` \| `深度稿` \| `短视频脚本` … |
| Skill 配合 | **不同体裁用不同叙事框架**（贴文可用 5W；南方周末长模板不适合作短帖） |

### 3. 【P1】人机协同工作流（可停顿确认）

老师在快速会议用舆情系统举例（约 09–22 分）：

> 讲好中国故事也要有工作流：定主题 → 调工具 → 喂资料 → 定口径/语气/变量/框架 → 初稿 → **多轮优化**；  
> 中间步骤可以停下来让用户确认、补充；也可以全自动跑。

前端建议形态：

| 元素 | 作用 |
|------|------|
| 步骤条 | 主题确认 → 资料/检索 → 口径与参数 → 初稿 → 反馈改稿 → 定稿 |
| 每步「确认 / 跳过」 | 对应老师说的人机交互停顿 |
| 反馈框 | 「哪里烂、哪里召回不准、叙事没用上」→ 触发再生成 / 记入评测反馈 |

### 4. 【P1】对话式交互（老师理想态）

老师原意（快速会议约 23:00）：

> 将来可以变成：**静态网页 + 旁边对话框**；即使没有华丽 UI，背后也可以跑复杂工作流。

| 建议 | 说明 |
|------|------|
| 双栏布局 | 左：成稿/预览/论据；右：对话（提问、改稿、追问库内容） |
| 与现侧栏 AI | 可演进为真正对话，而不只是提示芯片 |

### 5. 【P2】配图（下一阶段，非本周必须）

老师原意（约 31:15–33:06）：

> 配图最好 **AI 文生图**（版权风险小于随便下网络图）；  
> 需要带视觉能力的模型（千问 3.7/3.8 等广场模型）；  
> 先用千问付费额度，不必先上贵的 GPT。

前端预留：帖文区「生成配图」按钮；本阶段可灰显「下一阶段」。

### 6. 【P2】视觉参考竞品

老师原意（约 35:11）：

> 找不到开源就截竞品视觉，喂给 AI 生成；简单 UI 无侵权问题。  
> 陆好已借鉴三家模式 → **之后再调**，先保证逻辑点对。

## 二、前端已对齐、应保留的部分

| 已有能力 | 老师态度 |
|----------|----------|
| 三场景：主动发帖 / 选题 / 回复 | 认可主线；贴文先做好 |
| 参数：国家、语气、身份、平台 | 符合「中间让用户输入语气、长度、语言」 |
| 5W、正文、标签、运营建议、论据面板 | 贴文阶段输出项合理；类型可再扩展 |
| 论据可点开链接 | 老师追问后确认：须是**入库可引用**内容 |
| 门控 / 无证据即停可视化 | 与「证据可见、不瞎编」一致，建议保留 |
| 快捷改稿 | 属于人机改稿，可接到「多轮优化」 |

## 三、协作与部署（影响前端交付方式）

| 老师要求 | 含义 |
|----------|------|
| **不必先云部署** | 代码上 GitHub，组员本机安装依赖后跑前端（`127.0.0.1:端口`） |
| **Git 合并** | 各人改动 push / 分支 / merge，勿各传互不兼容的 zip 当唯一方式 |
| **后端可测** | Skill/工作流不必等前端；CLI/后端一样可测（刘璐提问时明确回答） |

## 五、建议的前端改版清单（按老师优先级）
