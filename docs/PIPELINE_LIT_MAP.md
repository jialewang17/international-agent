## 1. 知网精读文献（本组下载）

| 文献 | 核心结论（原文要点） | 本项目借鉴到哪里 |
|------|----------------------|------------------|
| 喻国明、刘瑞一、武丛伟《新闻人的价值位移与人机协同的未来趋势》，《新闻知识》2017 | 机器写作典型链为「抓取数据→分析→套模板→生成→**人工把关**」；人负责价值判断与深度，机器负责高效结构化生产 | **G3 证据汇聚 + Translate 成稿 + G7 人工定稿**；人机分工：机生成、人放行 |
| 刘鑫《人机协同视域下AI新闻写作的感知评价研究》，上外硕士论文 2025 | 实验表明受众对人机协同稿评价 **高于** 纯 AI / 纯人工；评价维含可信度、可读性、专业性 | **保留人机协同交互（G1 参数 + G6 改稿）**，不做「一键纯 AI 终稿」；成稿质量取向对齐可信/可读 |
| 毕文佳、李玉洁《AIGC对新闻真实性的冲击溯源及规制》，《全媒体探索》2024 | AIGC 冲击真实性：溯源模糊、形态失真、建构偏见；对策含规范、**人机协同治理**、技术透明度、信度效度 | **G3 证据可追溯 / 无证据即停**；结果展示 `evidence_used`；门控失败不硬生成 |
| 唐铮、白悦瑶《人工智能驱动下国际传播体系的赋能机制与优化方向》，《传媒》2026 | 提出国际传播「**数据层—技术层—内容层—分发层—认知层**」五层体系；生产含线索→编辑→分发反馈 | 总纲分层映射：资料/证据≈数据层，Skill/模型≈技术层，成稿≈内容层，平台参数≈分发层，受众国家/语气≈认知层 |
| 刘竞帆、刘震《AIGC赋能外籍博主国际传播的效能与边界》，《采写编》2026 | AIGC 助跨文化转译（语言/叙事/情感）；应以人的**文化判断力为锚**、AI 为增效；强调受众贴近与意义驱动 | **前端受众国/平台/语气选项（G1）**；Skill 管叙事框架；人确认口径与定稿，避免纯流量话术 |

## 2. 公开文献 / 产品（流程骨架）

| 文献或产品 | 借鉴要点 | 落到总纲环节 |
|------------|----------|--------------|
| Flower & Hayes, 1981；Gero et al., 2022 | 写作 = Plan / Translate / Review | G1–G4≈Plan；成稿≈Translate；G6–G7≈Review |
| Horvitz, CHI 1999 | 不确定才问；可跳过非关键自动化 | 可选门可跳过；硬门 G1/G3/G7 不可跳 |
| 江盈盈，2024（跨文化人机协同创意写作） | 调研→算法叙事+人整合→输出反馈 | 前端跨文化选项 + 成稿 + G6 反馈 |
| Paper Pilot；Verify-RAG；R³（系统/框架论文） | 证据锁定、批准门、改稿接受/拒绝 | G3 硬停；G7 放行；G6 改稿 |
| 知网智能写作产品形态 | 参数/大纲确认→生成→重写润色 | 表单确认→生成→润色/反馈改稿 |
| 郭亚军等《AIGC质量评估…》，《图书情报工作》2024（本组评测库已用） | 可追溯、可塑性、可解释 | `skills_applied` / `evidence_used` / 门决策日志 |
| 会议 0822 + 前端需求纪要 | 主题→资料→口径→初稿→多轮优化 | 与 G1–G7 步骤条一一对应 |

## 3. 流程简图（与文献对应）

```text
[喻：抓取/分析]  双源证据          ← 毕文佳：可追溯 / 无证据停
        │
[唐：数据→内容]  Skill + 成稿       ← 刘竞帆：跨文化参数 + 叙事插件
        │
[喻：人工把关]   G6 改稿 → G7 定稿  ← 刘鑫：人机协同优于纯 AI
```

| 步骤 | 做什么 | 主要文献锚点 |
|------|--------|--------------|
| G1 主题/体裁/受众 | 前端一次选齐 | 刘竞帆；会议 0822；Horvitz |
| G2 Skill 套件 | 注入 intl_comm+体裁 skill | 本组 skill 工程；唐铮「技术/内容层」 |
| G3 证据硬门 | 双源合并，空或错位则停 | 喻国明链；毕文佳溯源 |
| G4 口径（可跳） | 语气/长度等已在表单则跳过 | 会议 0822；知网写作产品 |
| 成稿 Translate | Prompt+Skill 生成 | Flower&Hayes；喻国明「生成」 |
| G6 改稿 | 润色/反馈再生成 | R³；刘鑫人机协同；知网润色 |
| G7 定稿 | 人工放行 | 喻国明「人工把关」 |

## 4. 不同提示词如何变（简表）

| 提示/体裁 | 路径变化 | 文献侧说明 |
|-----------|----------|------------|
| 帖文（默认） | 主线 + 5W skill | 唐铮：社媒个性化叙事 |
| 通稿 news | 换 news skill/prompt，口径更严 | 喻/刘鑫：结构化新闻生产 |
| 特稿 feature | 换 feature 框架 | 本组南周方法 skill |
| 脚本 script | 直接生成并标 incomplete，可改稿 | 毕文佳：仍须人审真实性 |
| 回复 reply | ABSA→检索→回复支线 | 刘竞帆：跨文化回应与转译 |
