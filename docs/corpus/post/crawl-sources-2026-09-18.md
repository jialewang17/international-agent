# 社交帖文爬取素材存档（摘要版）

采集：2026-09-18。完整结构蒸馏见 `skills/genres/china-story-post-reference.md`。

## 来源与内容摘要

### 1. Joanne Tai — 60 Instagram captions for China
- URL: https://joannetai.com/blog/china-captions
- 内容类型：分城英文短 caption + 少量中英双语
- 可用：地点锚（重庆山地、上海石库门/天际线、广州早茶承诺感）、古今反差一句
- 禁用示例：猎奇饮食刻板句（four legs except tables…）

### 2. Trip.com Moment — 高铁夜奔乌镇
- URL: https://pk.trip.com/moments/detail/tongxiang-220-144515575
- 内容类型：第一人称旅行叙事（接近长 caption / thread）
- 结构：周五下班钩子 → 买高铁票 → 夜景感官链（灯/水/糕/巡游）→ 茶馆一句对话 → 「慢下来」收束 → Practical tips 外置
- 注意：文中票价/车次仅结构参考，成稿须有 evidence 才可写数字

### 3. China Daily — History on the plate（姜小金）
- URL: https://www.chinadaily.com.cn/a/202601/23/WS6972e974a310d6866eb3562e.html
- 内容类型：短视频创作者方法 + 民族饮食故事
- 结构：好奇问句钩子 → 一分钟讲一道菜来历 → 服饰/成菜收尾；强调图书馆考证、拒绝不可靠起源传说
- 对 skill：TikTok 口播感、Says What 要具体到「一道菜/一个场景」

### 4. CGTN — As chill as the pandas in Sichuan
- URL: https://news.cgtn.com/news/2025-12-23/As-chill-as-the-pandas-in-Sichuan-1JkTlqfjv6U/p.html
- 内容类型：旅行短片导语式海外向文案
- 结构：标题钩子 → 当地词 *bashi* → 茶馆/大佛/采耳/熊猫场景串 → 慢生活邀请
- 对 skill：To Whom 当地词桥梁；单帖勿堆成成就清单

### 5. UNESCO — Traditional tea processing… (China)
- URL: https://ich.unesco.org/en/RL/traditional-tea-processing-techniques-and-associated-social-practices-in-china-01884
- 内容类型：非遗条目说明
- 要点：六大茶类；茶在家庭/职场/茶馆待客与社交；技艺代际传承
- 对 skill：权威轻点进正文，服务日常场景

### 6. 反例（空壳 caption 站）
- CaptionMode / Capsioney 等「Culture speaks quietly」「Tradition meets today」类无场景句
- 用途：标定不合格 Says What（口号/诗句空壳）
