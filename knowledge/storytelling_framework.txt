====================================================================
  storytelling_framework.txt
  国际传播中国故事叙事结构 —— AI Agent 知识规则
  基于25篇CGTN/China Daily/Xinhua English/People's Daily Online
  中国主题报道（2026.07-08）的开放编码分析
====================================================================

【重要说明】
本框架中的所有规则均来自对25篇国际传播媒体中国主题报道文本的实际分析，
不基于任何预设理论。每个模块的形成依据均可追溯到具体案例。

====================================================================
模块体系概览
====================================================================

  [必选模块] A+B+C   (25篇中100%/96%/92%出现)
  [扩展模块] D/E/F   (25篇中56%/48%/52%出现)
  [特殊模块] G/H     (25篇中28%/32%出现)

Agent生成任何中国主题报道时，必须包含必选模块A+B+C，
并根据主题和文体选择性地激活扩展模块和特殊模块。

====================================================================

【必选模块A】现状起点标识
====================================================================

形成依据：
  全部25篇样本文本均在首段或前两段完成叙事起点标识。
  案例1以问题切入("AI耗电")，案例2以数据发布切入，案例3以产品发布切入，
  案例7以场景描写切入(大织机)，案例16以人物回忆切入，案例23以事件公告切入。

调用条件：
  所有报道类型必须使用。是叙事的第一句/第一段的组织原则。

生成规则：
  1. 在报道首段或前两段中，明确回答"为什么现在讲这个故事"。
  2. 起点类型根据主题选择：
     - 科技报道：问题驱动(如"AI产业爆发带来XX挑战")或事件驱动(如"XX产品发布")
     - 文化报道：场景/器物引入(如"在XX博物馆的展厅里...")或人物引入
     - 生态报道：空间状态描述或政策目标发布
     - 社会报道：人物引入或数据对比
     - 国际合作：事件节点(如奠基仪式)或趋势判断(如"全球金融格局正在...")

注意事项：
  避免以"中国在XX领域取得了显著成就"类总结性陈述作为起点。
  应以具体而非抽象的方式打开叙事。

====================================================================

【必选模块B】中国行动展示
====================================================================

形成依据：
  24/25样本包含此模块（案例8为纯展示平台例外）。
  案例1展示系统性政策布局，案例2展示产业体系建设，案例3展示企业技术突破，
  案例7展示传承人个人努力+机构支持，案例13展示制度建设，
  案例16展示扶贫协作机制，案例22展示基础设施建设+教育培训+技术转移。

调用条件：
  所有报道类型必须使用。构成报道的实体内容主体。

生成规则：
  1. 明确描述"中国做了什么"——不只是"取得了成就"，而是"通过什么方式"。
  2. 根据主题选择和组合行动维度：
     - 科技：技术参数+研发路径+应用场景
     - 文化：传承行动+创新尝试+推广方式
     - 生态：治理工程+制度建设+产业转化
     - 社会：制度安排+个体参与+资源投入
     - 国际合作：项目建设+机制设计+理念推广
  3. 行动描述应包含"谁在做"（行动主体）和"怎么做"（行动方式），
     而非仅描述结果。

注意事项：
  避免仅罗列成就而无行动过程的空洞表述。
  行动主体的选择影响报道调性（政府/企业/个体/混合）。

【必选模块C】意义延伸连接
====================================================================

形成依据：
  23/25样本包含此模块（案例11视频报道、案例18体验报道例外）。
  案例1连接至"气候目标+工程反馈循环"，案例7连接至"UNESCO非遗+全球魅力展现"，
  案例14通过留学生话语连接至"中国现代化的另一面"，
  案例16连接至"全国东西部协作机制完善"，案例21连接至"21世纪全球秩序重塑"。

调用条件：
  所有报道类型必须使用。通常位于报道后半部分或结尾。

生成规则：
  1. 在报道的后半部分（通常为最后1/3），将具体事件连接至更大意义框架。
  2. 连接方向选项（可多选，但需与内容自然关联）：
     - 全球影响/国际意义
     - 社会价值/民生改善
     - 文化价值/文明延续
     - 政策示范/可复制性
     - 未来发展/趋势展望
  3. 连接方式可以是显性（直接陈述"这意味着..."）或隐性（通过他人话语/数据暗示）。
  4. 在评论文体中，意义延伸可贯穿全文而非仅结尾。

注意事项：
  避免"拔高"感——连接应基于报道中已呈现的具体内容，而非凭空嫁接高大主题。
  意义延伸的力度应与报道的"事实密度"匹配。

【扩展模块D】蜕变对比框架
====================================================================

形成依据：
  14/25样本（56%）包含此结构。案例1(AI耗电→解决方案)，
  案例7(失传风险→时尚符号)，案例14(荒地→葡萄酒产区)，
  案例16(西海固贫困→闽宁繁荣)，案例19(深山→国际画展)，
  案例22(内陆国→区域枢纽)。

调用条件：
  当报道主题涉及可观测的状态变化时使用。适用于：
  - 生态修复/环境治理主题
  - 脱贫攻坚/乡村振兴主题
  - 文化遗产从濒危到焕新的主题
  - 科技从瓶颈到突破的主题
  - 基础设施建设改变区域面貌的主题

生成规则：
  1. 明确描述三种状态：
     - 初始状态：具体描述"之前是什么样的"（用感官细节、具体数据或人物感受）
     - 转变过程：连接初始与实现状态的行动链
     - 实现状态：具体描述"之后是什么样的"（与初始状态形成可对比的描述）
  2. 对比应有物质锚点（不只是"变得更好了"）：
     - 案例16用"灯亮了+水流了"vs"从岩石缝隙中渗水"
     - 案例14用"葡萄藤覆盖"vs"砾石荒地"
     - 案例19用"3000幅/100万"vs"仅有初中文化程度"
  3. 变化幅度的大小决定该模块在整个报道中的篇幅占比。

注意事项：
  避免"一年一小变、三年一大变"式的空洞对比。
  初始状态的描述必须同样真实具体，不可为了衬托效果而过度丑化。

【扩展模块E】个体人物聚焦
====================================================================

形成依据：
  12/25样本（48%）以个体人物为核心或重要叙事元素。
  案例7(周双喜)、案例14(三位留学生)、案例16(海国宝+吴娟)、
  案例19(赵元桥)、案例22(村长+毕业生+12岁男孩)、案例4(Larry Levene)。

调用条件：
  当需要通过"人的故事"使抽象议题可感知时使用。特别适用于：
  - 文化传承/非遗主题
  - 社会发展/民生主题
  - 任何需要情感共鸣的叙事场景
  不适用于：纯政策公告、纯数据发布型短讯、项目参数型报道

生成规则：
  1. 选择具有"代表性"但非"完美英雄"的个体：
     - 案例中多为普通人(农民、手工艺人、牧民、学生)而非精英
     - 案例7周双喜：18岁学徒起步，非天才叙事
     - 案例16海国宝：普通搬迁农民，以家人眼泪开场
  2. 个体的材料使用层次(由浅至深)：
     - Level 1: 作为叙事视角载体(如案例14留学生，通过其眼睛看)
     - Level 2: 作为核心经历者(如案例7周双喜，其生命轨迹即叙事主线)
     - Level 3: 作为话语来源(直接引用其感受和判断)
  3. 个体的故事应自然通向更大的主题，而非割裂的"人物特写+政策说明"两段式。

注意事项：
  避免模板化的"典型人物"塑造——不必是完人，容许有困难、有挣扎、有不确定。
  案例22罕见地保留了学生记录的基础设施不足观察，这是该模块可容纳的"真实感"元素。

====================================================================

【扩展模块F】权威数据辅证
====================================================================

形成依据：
  13/25样本（52%）包含功能性数据（非装饰性数据）。
  案例2(产业规模、增速、细分占比、区域集中度)，
  案例3(2.4万亿参数、API定价比例、Arena排名)，
  案例16(人均收入、脱贫人数、装机容量)，
  案例22(货运量增长、货物种类、贸易伙伴)。
  案例23(建筑面积、手术室数、床位数)。

调用条件：
  当报道需要建立可信度和规模感时使用。特别适用于：
  - 产业/经济类报道
  - 科技技术类报道
  - 基建项目类报道
  - 任何需要"可验证性"的叙事场景

生成规则：
  1. 数据应服务于叙事，而非数据堆砌：
     - 好：案例22"他最新一季玉米收成卖出了800万基普"——数据讲述个人故事
     - 差：脱离叙事上下文的数据罗列
  2. 数据使用的层次：
     - Level 1: 宏观锚定(如"1.2万亿"、"全球15%")
     - Level 2: 过程量化(如"年均增长17%"、"运输3900+种货物")
     - Level 3: 个体维度(如"每幅100元"、"每天5-6厘米")
  3. 关键数据应包含可比维度(同比、占比、国际比、前后比)。

注意事项：
  数据需要语境化——"100万元"在贵州深山的文化冲击力远大于在一线城市。
  数据不应替代叙事而成为叙事的全部(案例2接近此边界但仍有政策行动模块)。

【特殊模块G】他者视角嵌入
====================================================================

形成依据：
  7/25样本（28%）包含此模块。
  案例4(西班牙电影人Levene)、案例10(外国人的文化融入趋势)、
  案例14(三位外国留学生)、案例22(中国志愿者团队的田野观察)。

调用条件：
  当需要"第三方在场"的叙事合法性时使用。特别适用于：
  - 需要展示外部接受度的文化/技术传播主题
  - 需要跨文化视角验证的发展变化主题
  - 面向国际受众的软性报道
  不适用于：政策公告、数据通报、发言人表态类报道

生成规则：
  1. 他者视角应具有叙事功能，而非仅作为"外国人说好"的装饰性引用：
     - 功能A：提供认知转变弧线(案例14 Valeriya："I used to think...In Ningxia, I saw another side")
     - 功能B：提出反思性维度(案例4 Levene结尾的伦理追问)
     - 功能C：作为田野观察者记录(案例22志愿者对配套不足的观察)
  2. 他者的话语应有具体内容，而非泛泛的"amazing/impressive"。

注意事项：
  避免将他者视角简化为"外国人也说好"式的验证工具。
  容许他者提出疑问或不完全正面的观察——这正是真实性的来源。

====================================================================

【特殊模块H】隐喻概念锻造
====================================================================

形成依据：
  8/25样本（32%）包含贯穿性隐喻。
  案例1("guzzles electrons"、神经系统)、案例11("industrial scar")、
  案例14("take root"葡萄藤扎根)、案例16("干沙滩→金沙滩→数字黄金")、
  案例17("做大蛋糕")、案例21("building bridges"、"plumbing of global finance")。

调用条件：
  当面向非专业国际受众、需要降低认知门槛时使用。特别适用于：
  - 复杂技术/经济概念的通俗化传播
  - 需要跨文化可传播性的标题和核心段落
  - 篇幅较长的深度报道
  不适用于：短讯、纯技术参数通报

生成规则：
  1. 隐喻来源应来自跨文化可理解的日常经验：
     - 物理世界(桥梁、管道、伤疤、喝水、扎根)
     - 人体/生命(神经系统、成长)
     - 日常生活(做蛋糕、沙变金)
  2. 隐喻应服务于概念传递，可出现在三个位置：
     - 标题层：案例11"From industrial scar to green park"
     - 关键词段：案例21"building bridges, not barriers"
     - 贯穿全文的意象：案例1"神经系统"在多个段落重现
  3. 隐喻不能替代事实——它是"包装"而非"内容"。

注意事项：
  避免生造隐喻——应使用已经在跨文化语境中被广泛理解的意象。
  避免隐喻过度——一个贯穿性隐喻优于多个散乱比喻的堆砌。

====================================================================
Agent 主题-模块匹配决策表
====================================================================

生成报道时，Agent应根据以下决策表选择模块组合：

| 主题     | 必选     | 优先激活       | 可选激活       |
|---------|---------|---------------|---------------|
| 科技发展  | A+B+C   | D(蜕变) F(数据) | E(个体) H(隐喻) |
| 文化传播  | A+B+C   | E(个体) D(蜕变) | H(隐喻) G(他者) |
| 生态发展  | A+B+C   | D(蜕变) F(数据) | E(个体) G(他者) |
| 社会发展  | A+B+C   | E(个体) D(蜕变) | F(数据) H(隐喻) |
| 国际合作  | A+B+C   | 因文体分化           |              |
|  └项目型  |          | F(数据) E(个体) | D(蜕变) G(他者) |
|  └理念型  |          | H(隐喻)        | F(数据)       |

====================================================================
Agent 禁止清单
====================================================================

1. 禁止以"中国在XX领域取得了显著成就"类总结性陈述作为叙事起点。
2. 禁止使用无具体内容的泛化赞美词汇("great"/"remarkable"/"impressive"
   作为独立陈述；如引用他人话语则可)。
3. 禁止在蜕变框架中过度丑化"变化前"以突出"变化后"。
4. 禁止将他者视角简化为"外国人也说好"式验证。
5. 禁止数据堆砌——每个数据都应有叙事功能。
6. 禁止在缺乏事实基础的情况下进行意义延伸——"拔高"会损伤可信度。
7. 禁止将个体人物塑造为完美英雄模板。

分析基础：25篇国际传播文本的开放编码
覆盖来源：CGTN(6) / China Daily(5) / Xinhua English(7) / People's Daily Online(7)
覆盖主题：科技(5) / 文化(5) / 生态(5) / 社会(5) / 国际合作(5)
分析原则：所有结论来自样本文本，不作理论预设
