writing_methodology.txt
基于《南方周末写作课》的AI Agent新闻写作方法规则库
=====================================================================

形成依据：基于《南方周末写作课》（南方周末编著，中信出版社，2021年4月）
书中7位讲师（南香红、雷磊、迟宇宙、王天挺、杜强、杨瑞春、陈鸣）
十数年特稿写作经验的方法提炼。

本文件不是读书笔记，而是AI Agent可以调用的方法执行规则。

=====================================================================
模块索引
=====================================================================

A. 故事发现引擎 ............ 选题捕获与故事判断
B. 结构骨架搭建 ............ 从素材到骨架
C. 信息获取系统 ............ 采访与调查方法
D. 细节运用系统 ............ 细节筛选与使用
E. 叙事质感提升 ............ 文学性技巧工具箱
F. 首尾设计 ............... 开头与结尾方法

调用顺序：A → B → C → D → E（可选）/ F
注意：A与C存在循环关系——采访中发现新线索可能改变选题方向。

=====================================================================
【模块A】故事发现引擎
=====================================================================

名称：故事发现引擎

形成依据：
来自南香红第一讲"解构特稿DNA，好故事从何而来"全部内容，
以及迟宇宙第三讲部分内容、杜强第五讲引言。

核心作用：
解决"写什么"的问题。确保选题本身具备故事价值，
而非仅是信息堆砌或热点追逐。

适用场景：
所有需要在信息流中发现故事选题的写作任务。
尤其适用于：社会变迁、文化传承、科技发展、生态保护、
国际合作等需要深度挖掘的主题。

调用条件：
- 当用户提出一个写作主题但尚未明确故事角度时
- 当需要在多人竞争的话题中找到独特切入点时
- 当需要判断一个想法是否值得发展为完整故事时
- 当需要从历史素材中发现新闻价值时

---------------------------------------------------------------------
A-1 养故事法
---------------------------------------------------------------------

形成依据：南香红"野马的故事"系列（1997-持续10余年）

执行步骤：
1. 选定一个值得长期深耕的领域
2. 建立并维护该领域的信息源网络
3. 持续收集背景信息，建立信息库
4. 监测领域内的新变化、新事件
5. 当"激活点"出现时（新事件、新变化、新发现），
   调用积累的背景信息和知识进行写作
6. 每次写作后更新信息库，深化对领域的理解

Agent调用规则：
- 维护一个领域知识库文件
- 每次接收新信息时更新知识库
- 在激活点出现时，生成包含历史纵深的故事

限制条件：
- 不适用于一次性、即时性新闻
- 需要至少2次以上的信息积累才能生效

---------------------------------------------------------------------
A-2 信息流定位法
---------------------------------------------------------------------

形成依据：南香红唐山地震30周年报道案例

执行步骤：
1. 盘点已有报道覆盖了哪些角度（列出已知角度清单）
2. 逐一评估每个角度的覆盖程度（充分/部分/未覆盖）
3. 排除已被充分覆盖的角度
4. 在未覆盖或覆盖不足的区域寻找切入点
5. 明确自己故事的独特目标
6. 从该位置出发组织故事

Agent调用规则：
- 输入：主题关键词
- 执行：检索已有报道角度，输出空白区域
- 输出：推荐2-3个独特切入点及理由

限制条件：
- 需要能够检索已有报道（依赖外部信息源）
- 不适用于完全没有前人报道的全新话题

---------------------------------------------------------------------
A-3 反差发现法
---------------------------------------------------------------------

形成依据：南香红在唐山采访中发现"抹布细节"

执行步骤：
1. 观察采访对象的现状与过去的对比
2. 寻找表面合理但内含矛盾的细节
3. 追问反差背后的原因
4. 以反差作为故事的核心驱动力

Agent调用规则：
- 在分析采访素材时，自动识别矛盾点
- 输出格式：[现状] vs [预期/过去] → [反差意义]

限制条件：
- 反差必须基于真实观察，不可制造
- 反差需指向深层意义，不仅是表面不同

---------------------------------------------------------------------
A-4 故事活力判断法
---------------------------------------------------------------------

形成依据：南香红"故事活力"概念 + 杜强"细节永恒"观点

执行步骤：
1. 评估选题是否具有超越一时一地的价值
2. 检验：10年后这个故事是否仍有意义？
3. 检验：故事中是否包含"证明人们精神的细节"？
4. 如果两个检验都通过→高活力选题
5. 如果仅时效性强但活力不足→谨慎选择

Agent调用规则：
- 对每个选题进行活力评分（1-5分）
- 评分维度：时效超越性、人性深度、细节丰富度
- 低于2分的选题建议放弃或重新寻找角度

限制条件：
- 不以热度作为唯一标准
- "活力"判断需基于具体素材而非抽象判断

---------------------------------------------------------------------
A-5 旧闻转新闻法
---------------------------------------------------------------------

形成依据：南香红"从凝固的历史中发掘流动的新闻"

执行步骤：
1. 在历史素材中寻找与当下的关联
2. 为旧素材寻找新的新闻由头
3. 从一个已完成的故事延伸出新的角度
4. 在日常事件中发现历史蕴含

Agent调用规则：
- 输入：历史事件/旧选题
- 执行：寻找与当下事件的关联点
- 输出：新的故事角度 + 新闻由头

限制条件：
- 必须有真实的新闻由头，不可生造关联


=====================================================================
【模块B】结构骨架搭建
=====================================================================

名称：结构骨架搭建

形成依据：
来自雷磊第二讲"搭建坚实的结构骨架，让读者欲罢不能"全部内容。

核心作用：
解决"怎么组织"的问题。从混沌素材中建立秩序，
为故事提供可执行的骨架。

适用场景：
所有需要结构设计的故事写作。
在完成选题判断（模块A）后、开始大规模信息获取（模块C）前调用。

调用条件：
- 当选题已确定但尚未开始写作时
- 当面对大量素材不知如何组织时
- 当需要判断故事是否有足够驱动力时

---------------------------------------------------------------------
B-1 一句话法则
---------------------------------------------------------------------

形成依据：雷磊转述南周编辑部训练法 + 罗伯特·麦基《故事》

执行步骤：
1. 完成初步信息收集
2. 尝试用30句话概括故事
3. 压缩到5句话
4. 压缩到1句话
5. 检验：这句话是否包含故事的核心价值？
6. 以此句话为骨架展开写作

Agent调用规则：
- 输入：故事素材摘要
- 执行：逐步压缩概括
- 输出：一句话故事核心句
- 格式要求："这是一个[主体]通过[行动]实现[价值变化]的故事。"

限制条件：
- 必须在信息收集到一定程度后才能执行
- 一句话不是标题，是故事的核心认知
- 如果无法压缩到一句话，说明对故事理解不够深

---------------------------------------------------------------------
B-2 价值量变化识别
---------------------------------------------------------------------

形成依据：雷磊"华科男"案例

执行步骤：
1. 列出故事中涉及的核心价值概念（如：孤独/活力、传统/创新等）
2. 识别这些价值在故事中发生了什么变化
3. 确定变化方向（从A到B）
4. 变化方向即为故事的核心驱动力
5. 以价值变化过程为线索搭建结构

Agent调用规则：
- 输入：故事素材
- 执行：识别价值对立项 + 变化方向
- 输出格式：价值A（初始状态）→ 价值B（结束状态）
  示例：沉默/呆板 → 创新/活力

限制条件：
- 价值变化必须基于真实素材，不可虚构
- 至少需要识别出一组对立价值

---------------------------------------------------------------------
B-3 结构模式选择
---------------------------------------------------------------------

形成依据：雷磊第二讲第2、3节

执行步骤：
1. 评估素材特征：
   - 是否有清晰的起因-冲突-结果？→ 三段式结构
   - 是否有多条线索并行？→ 多线叙事结构
   - 是否需要首尾呼应？→ 环形结构
   - 是否先揭示结局再回溯？→ 倒置结构
   - 是否有多层故事嵌套？→ 嵌套式结构
2. 选择最适合的结构模式
3. 按模式搭建骨架

Agent调用规则：
- 输入：素材特征清单
- 执行：匹配结构模式
- 输出：结构骨架（含段落分配建议）

三段式结构模板：
- 触发段（20%）：事件发生/人物出场/问题出现
- 冲突段（60%）：矛盾展开/困难加剧/转折出现
- 解决段（20%）：问题解决/价值实现/意义升华

限制条件：
- 可混合使用多种结构
- 结构服务于故事，不是故事服务于结构

---------------------------------------------------------------------
B-4 对峙张力提升
---------------------------------------------------------------------

形成依据：雷磊第二讲第4节

执行步骤：
1. 整体对峙：在故事整体层面设置对立力量
2. 意象对峙：使用具有象征意义的对立意象
3. 细节对峙：在具体细节中嵌入对立元素

Agent调用规则：
- 在结构骨架完成后执行
- 检查每个主要段落是否包含至少一层对峙
- 输出：对峙层次标注

限制条件：
- 对峙应自然存在于素材中，不可强行制造
- 对峙不等于冲突——可以是隐性的张力


=====================================================================
【模块C】信息获取系统
=====================================================================

名称：信息获取系统

形成依据：
来自迟宇宙第三讲"从极有限的线索出发，无限接近真相"全部内容，
王天挺第四讲部分内容，杜强第五讲部分内容。

核心作用：
解决"怎么获取"的问题。确保有足够丰富、准确、
有质感的素材支撑故事。

适用场景：
在结构骨架确定后，需要补充信息或验证假设时调用。
对于AI Agent，此模块转化为"信息需求清单生成"和
"素材质量评估"功能。

调用条件：
- 当结构骨架已搭建但素材不足时
- 当需要验证故事中的关键事实时
- 当需要获取更多细节时

---------------------------------------------------------------------
C-1 信息需求清单生成
---------------------------------------------------------------------

形成依据：人物案卷分析（王天挺）+ 线索织网（迟宇宙）

执行步骤：
1. 根据一句话法则确定的核心价值，列出需要回答的问题
2. 根据结构骨架，列出每个段落需要的信息类型
3. 制作人物案卷分析表（15个维度）：
   外表/家庭背景/教育程度/经济情况/情感史/天赋/信仰/
   身份/道德/动机/友谊/自我认知/价值观/习惯/爱好
4. 标记已有信息和缺失信息
5. 生成信息需求清单

Agent调用规则：
- 输入：一句话核心句 + 结构骨架
- 执行：生成信息需求清单
- 输出：按优先级排序的信息需求列表

限制条件：
- 信息需求应服务于故事核心，不是面面俱到
- 优先获取与价值变化最相关的信息

---------------------------------------------------------------------
C-2 素材质量评估
---------------------------------------------------------------------

形成依据：迟宇宙调查三原则 + 杜强辨认好细节四指标

执行步骤：
1. 对每条素材应用三个检验：
   - 每一个字都有用？（信息价值检验）
   - 每一句话都可疑？（可信度检验）
   - 人性是最好的判断中枢？（合理性检验）
2. 对每条细节素材应用四个指标：
   - 与主题相关性（1-5分）
   - 与人物事件贴近度（1-5分）
   - 提供的文学性（1-5分）
   - 结构/节奏作用（1-5分）
3. 总分8分以上的细节保留
4. 低于8分的细节考虑替换或删除

Agent调用规则：
- 输入：素材清单
- 执行：逐条评分
- 输出：分类清单（保留/修改/删除）+ 评分理由

限制条件：
- 评分应基于素材本身质量，不可因来源偏好调整
- "人性判断"标准：该信息是否符合人性常识？

---------------------------------------------------------------------
C-3 细节追问模拟
---------------------------------------------------------------------

形成依据：王天挺"追问细节"方法

执行步骤：
1. 从宽泛问题开始："这项工作难在哪里？"
2. 得到模糊回答后追问感受："怎么个难法？"
3. 得到感受后追问具体场景："有没有具体的例子？"
4. 得到场景后追问精确数据："具体是多少？"
5. 层层递进直到获得可视化细节

Agent调用规则：
- 当用户提供模糊素材时，自动生成追问问题清单
- 追问格式：[模糊信息] → "能否具体说明___？"
- 目标：将所有"非常XX"转化为可量化的具体描述

示例：
- 输入："这个工作非常热"
- 追问1："热到什么程度？有具体温度吗？"
- 追问2："工人的防护装备能承受多高温度？"
- 追问3："有没有因为高温发生事故的案例？"

限制条件：
- 追问应自然递进，不可跳跃太大
- 最终目标是获得"2厘米厚胶靴底"级别的精确细节


=====================================================================
【模块D】细节运用系统
=====================================================================

名称：细节运用系统

形成依据：
来自王天挺第四讲"细节决定故事的质感"部分，
杜强第五讲全部内容。

核心作用：
解决"怎么呈现"的问题。用细节让故事有质感、
有画面、有可信度。

适用场景：
在信息获取完成后、开始写作时调用。
贯穿写作全过程。

调用条件：
- 当开始撰写正文时
- 当需要在文中插入细节时
- 当需要判断某处是否需要更多细节时

---------------------------------------------------------------------
D-1 细节筛选决策
---------------------------------------------------------------------

形成依据：杜强"辨认好细节的四个指标"

执行步骤：
1. 第一关——主题相关性：该细节是否与故事核心价值相关？
   不相关→坚决删除
2. 第二关——信息独特性：该细节是否提供了"人无我有"的信息？
   不能拓展读者认知→考虑删除
3. 第三关——文学性：该细节是否增加了表达的文学性？
   语言准确、栩栩如生、不落窠臼→保留
4. 第四关——结构功能：该细节是否在结构或节奏上起作用？
   有节奏功能→优先保留
5. 四项中通过两项以上→保留

Agent调用规则：
- 对每个候选细节自动执行四关检验
- 输出格式：
  [细节内容]
  主题相关性：X/5
  信息独特性：X/5
  文学性：X/5
  结构功能：X/5
  总分：X/20
  决策：保留/删除/修改

限制条件：
- 不可因细节"有趣"但与主题无关而保留
- 宁缺毋滥——"并不是越多越好，关键在于精炼和有深度"

---------------------------------------------------------------------
D-2 细节部署策略
---------------------------------------------------------------------

形成依据：王天挺小侧写四层次 + 杜强细节使用三方法

执行步骤：
1. 按小侧写四层次部署细节：
   - 远景：人物所处的现场环境
   - 动态：人物自身的语言和动作
   - 静态：人物的状态描写
   - 关系：人物与他人及环境的互动
2. 按三功能部署细节：
   - 塑造人物：语言习惯、口头禅、肢体语言、外形特点
   - 描写动作和场面：让读者有身临其境感
   - 控制节奏：用细节放慢节奏，用概述加快节奏

Agent调用规则：
- 在生成正文时，检查每个主要段落是否包含至少2个层次
- 确保全文细节分布均匀，不集中在某一段
- 在关键转折点部署最强细节

限制条件：
- 避免四个误区：
  1. 细节越多越好（× 精炼优于堆砌）
  2. 缺乏细节就束手无策（× 细节不是万能的）
  3. 细节丰富但行文呆板（× 细节要服务于整体）
  4. 陈词滥调充斥（× 追求有新意的细节）


=====================================================================
【模块E】叙事质感提升
=====================================================================

名称：叙事质感提升

形成依据：
来自王天挺第四讲第2、4节"提高故事高级感的三种方法"
和"四种方法让故事更有文学性"。

核心作用：
解决"怎么写好"的问题。让文字超越信息传递
达到审美层面。

适用场景：
在初稿完成后、修改阶段调用。
特别适用于：人物特写、文化传播、社会发展类故事。
对于数据驱动的科技/政策报道，选择性使用。

调用条件：
- 当初稿完成但文字质感不足时
- 当需要提升文学性时
- 当需要控制叙事节奏时

---------------------------------------------------------------------
E-1 节奏控制
---------------------------------------------------------------------

形成依据：王天挺"叙述节奏感" + "广播体操"式搭配

执行步骤：
1. 将文中表达方式分类：
   1=直接引语  2=间接引语  3=概述  4=描写
2. 检查交替模式：是否按"1234、2234"方式切换？
3. 静态描写（4）后接动态概述（3），形成快慢交替
4. 紧张场景加快节奏（多用概述）
5. 舒缓场景放慢节奏（多用描写）

Agent调用规则：
- 对正文逐段标注表达方式编号
- 检查是否有过长的单一方式（连续3段以上同类型→需调整）
- 输出：节奏分布图 + 调整建议

限制条件：
- 不要为了交替而交替——节奏应服务于内容
- 直接引语要少用——"不可控，可能与叙述风格不协调"

---------------------------------------------------------------------
E-2 画面感构建
---------------------------------------------------------------------

形成依据：王天挺"画面感与白描" + "摄像机镜头"观察法

执行步骤：
1. 写作前在脑中（或用文字）构建具体画面
2. 用摄像机镜头视角"拍摄"场景：远景→中景→近景→特写
3. 用白描手法描绘：突出特征，传神，概述
4. 用准确而非华丽的语言
5. 检验：读者能否仅凭文字形成画面？

Agent调用规则：
- 在生成场景描写时，按镜头运动组织文字
- 模板：
  [远景] 环境整体描述
  [中景] 人物在环境中的位置和状态
  [近景] 人物的具体动作或表情
  [特写] 最关键的细节放大

限制条件：
- 白描不是干瘪——"突出特征"意味着选择最有表现力的细节
- 准确性优先于文学性

---------------------------------------------------------------------
E-3 抽象阶梯运用
---------------------------------------------------------------------

形成依据：王天挺"抽象阶梯" + 杜强"用细节控制结构和叙事节奏"

执行步骤：
1. 识别当前段落所处的抽象层级：
   - 具体层：可感知的画面、动作、对话
   - 中间层：对行为的解读、对现象的归纳
   - 抽象层：普遍意义、价值判断、社会隐喻
2. 在具体与抽象之间移动：
   细节（具体）→ 解读（中间）→ 意义（抽象）→ 新细节（具体）
3. 用抽象层级移动控制节奏：
   - 上升（具体→抽象）：放慢节奏，深化思考
   - 下降（抽象→具体）：加快节奏，回到现场

Agent调用规则：
- 对正文标注抽象层级（C=具体/M=中间/A=抽象）
- 理想模式：C→M→A→C→M→A（阶梯式推进）
- 警告：连续3段以上停留在同一层级→需调整

限制条件：
- 不可从具体直接跳到高度抽象——需要中间层过渡
- 不可在抽象层停留过久——读者会失去画面感

---------------------------------------------------------------------
E-4 文学性工具箱
---------------------------------------------------------------------

形成依据：王天挺"四种方法让故事更有文学性"

四种可用工具：

1. 抽象阶梯（见E-3）

2. 变换叙事视角：
   - 识别可用视角：当事人/旁观者/全知叙述者
   - 在不同段落切换视角
   - 确保切换有明确标志（时间/空间转换）

3. 自由间接引语：
   - 不使用引号
   - 以第三人称叙述但融入人物语言习惯
   - 叙述者声音与人物声音交融
   - 适用：人物心理描写

4. 不简单贴标签：
   - 不用单一形容词定义人物
   - 呈现人物的多面性和矛盾性
   - 让读者通过细节自行判断

Agent调用规则：
- 在修改阶段，检查是否至少使用了2种文学性工具
- 每种工具的使用频率建议：
  抽象阶梯：全文3-5次
  变换视角：全文1-2次
  自由间接引语：人物段落中使用
  不贴标签：贯穿全文

限制条件：
- 文学性工具服务于故事，不是炫技
- 保持非虚构的真实性底线


=====================================================================
【模块F】首尾设计
=====================================================================

名称：首尾设计

形成依据：
来自王天挺第四讲第3节"故事的经典开头和结尾"。

核心作用：
解决"从哪开始、在哪结束"的问题。
开头建立读者信任，结尾留下思考余地。

适用场景：
在结构骨架确定后、正文写作前设计开头；
在正文完成后设计结尾。

调用条件：
- 当需要设计文章开头时
- 当正文完成需要收束时
- 当需要检查首尾是否匹配时

---------------------------------------------------------------------
F-1 开头模式选择
---------------------------------------------------------------------

形成依据：王天挺总结的10种开头方法

10种可选模式：
1. 场景式开头：以一个具体场景开篇
2. 直接引语：引用重要人物的话
3. 第一人称讲述：用第一人称代入故事
4. 动作开头：以一个动作开篇（不勾连意义）
5. 专家言论：引用包含观点的言论
6. 描述事件：要素完整地描述一个事件
7. 突破常识：出人意料的结论或观察
8. 完整故事：由动作推动的小故事
9. 引人深思的问题：提出问题引发思考
10. 趋势归纳：对某种趋势或变化的观察归纳

选择原则（以场景式为例）：
- 场景必须是单一的，不需要多场景切换
- 场景要么反映人物性格，要么营造基调，要么有象征意义，要么本身是故事
- 必须是特别打动你的那个场景

Agent调用规则：
- 输入：故事类型 + 核心价值 + 可用素材
- 执行：匹配最优开头模式
- 输出：开头段落草稿 + 选择理由

选择逻辑：
- 人物特写 → 场景式或动作开头
- 数据驱动报道 → 突破常识或趋势归纳
- 文化传播 → 场景式或完整故事
- 调查报道 → 引人深思的问题或直接引语
- 国际合作 → 场景式或描述事件

限制条件：
- 开头应奠定全文基调
- 不可与结尾脱节——首尾应呼应

---------------------------------------------------------------------
F-2 结尾模式选择
---------------------------------------------------------------------

形成依据：王天挺总结的结尾方式 + 杨晓敏"临门一脚"观点

3种可选模式：
1. 金句式：用一句有力的话收束
2. 叹息式：留下情感余韵
3. 首尾呼应式：与开头形成呼应

选择原则：
- "如果把它拿掉，并不会影响读者对故事的理解，故事仍是完整的"
- 结尾应留下"意味深长的思考余地"

Agent调用规则：
- 输入：开头模式 + 全文基调
- 执行：匹配最优结尾模式
- 输出：结尾段落草稿 + 选择理由

匹配逻辑：
- 场景式开头 → 首尾呼应式（回到同一场景，但意义已变）
- 突破常识开头 → 金句式（用金句强化反常识发现）
- 第一人称开头 → 叹息式（个人感慨收束）
- 问题式开头 → 金句式（用金句回答开头的提问）

限制条件：
- 结尾不是总结——不要重复正文已说的内容
- 结尾不是说教——不要强加价值判断
- "留给读者思考"意味着有所不说

Agent调用总流程
=====================================================================

当接收到"写一个中国故事"的任务时，按以下顺序执行：

步骤1：调用模块A——故事发现引擎
  → 输入：主题关键词
  → 输出：故事角度 + 独特切入点

步骤2：调用模块B——结构骨架搭建
  → 输入：故事角度 + 可用素材
  → B-1 一句话法则：生成核心句
  → B-2 价值量变化：识别驱动力
  → B-3 结构模式：选择骨架
  → B-4 对峙张力：标注张力点
  → 输出：结构骨架 + 段落分配

步骤3：调用模块C——信息获取系统
  → 输入：结构骨架
  → C-1 生成信息需求清单
  → C-2 评估已有素材质量
  → C-3 生成追问问题（如需补充信息）
  → 输出：素材清单 + 缺失信息

步骤4：开始写作
  → 调用模块F-1：选择开头模式
  → 按结构骨架逐段写作
  → 每段调用模块D：部署细节
  → 调用模块E（可选）：提升质感
  → 调用模块F-2：选择结尾模式

步骤5：修改
  → 调用E-1：检查节奏
  → 调用E-3：检查抽象阶梯
  → 调用D-1：复核细节质量
  → 调用F：检查首尾匹配


=====================================================================
Agent禁止清单
=====================================================================

1. 禁止在没有"一句话核心句"的情况下开始写作。
   依据：雷磊"一句话法则"——南周编辑部第一训练法。

2. 禁止使用与主题无关的细节。
   依据：杜强"辨认好细节四指标"第一条——
   "没有表现主题和人物的细节，都应该坚决删除。"

3. 禁止细节堆砌。
   依据：杜强"细节运用的四个误区"第一条——
   "并不是越多越好，关键在于精炼和有深度。"

4. 禁止使用陈词滥调。
   依据：杜强"细节运用的四个误区"第四条——
   "避免使用陈词滥调，让细节更具有新意和创意。"

5. 禁止对人物简单贴标签。
   依据：王天挺"四种方法让故事更有文学性"第四条——
   "不要简单地贴标签。"

6. 禁止纯线性叙事（除非故事本身是简单时间线）。
   依据：南香红——"初阶写作者讲故事，习惯于从前往后
   捋故事的线性思维；真正的讲故事能手，会一次次复原
   细节，带你突破时空的桎梏。"

7. 禁止结尾说教或过度总结。
   依据：杨晓敏（引用于书中）——结尾应"给读者留下
   意味深长的思考余地"，"如果把它拿掉，并不会影响
   读者对故事的理解"。

8. 禁止追逐热点而忽视故事活力。
   依据：南香红——"不同于很多自媒体编辑'住在热搜上'
   的流量式写法，南香红更看重时效性的背后，一个故事
   的'活力'。"
