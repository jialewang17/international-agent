## 一、语料摘录（可执行片段，非全文照抄）

### A1 Joanne Tai · 分城短 caption（学：地点锚 + 可读钩子）

**合格倾向（有地点/反差）：**
- *Chongqing: uphill, downhill, somehow still uphill*
- *Old shikumen, new skyline – Shanghai contains multitudes*
- *Ancient enough to humble you, modern enough to surprise you*
- *In Guangzhou, breakfast isn’t a meal. It’s a commitment.*（需有 evidence 支撑饮食主张时才可仿写具体断言）

**禁止照搬（刻板/冒犯风险）：**
- *They eat everything with four legs except tables…*（猎奇饮食刻板，违反 intl-comm 与证据规则）

**蒸馏：** 短帖也要有**城市/场景锚**；双关可用，但不得替代可核验主点；猎奇刻板句一律禁用。

### A2 Trip.com 乌镇夜奔（学：微型旅程弧 + tips 外置）

结构观察：
1. **时间钩子**：Friday 6pm / 不想回家  
2. **行动**：打开 12306 → 高铁 → 夜景区  
3. **感官链**：灯影水面、青石湿润、丁蹄糕、吉他、蚕花仙子巡游  
4. **人物一句**：茶馆老板「乌镇的夜不等赶路的人」  
5. **收束情绪**：slow down（非「伟大中国」口号）  
6. **Practical tips** 单独成块（车次、票价、开放时间）——对应本项目 `ops_tips`，**不与故事正文抢戏**

**蒸馏：** 中长 IG caption ≈ 钩子场景 → 感官/人物细节 → 轻意义 →（可选）轻提问；数字进 tips 或 evidence。

### A3 China Daily · 姜小金（学：短视频/口播帖的钩子问句）

结构观察：
- 开场问句：冬至为何吃饺子？蛋炒饭是否曾是御膳？  
- 一分钟：来历短剧 → 服饰/成菜展示  
- 工作流：图书馆考证 3–5 天；拒绝未经核验的民间起源传说  
- 一道菜牵一条民族/地方史（如柯尔克孜奶疙瘩）

**蒸馏：** TikTok/口播感帖可用 **好奇问句钩子**；Says What = 一道具体食物/场景的可核验点；无考证材料则不写起源断言。

### A4 CGTN 四川 *bashi*（学：当地词桥梁 + 场景串）

结构观察：
- 标题钩：为何熊猫这么 chill？  
- 当地词 *bashi*（自在、舒服）作 To Whom 桥梁  
- 场景串：方言 / 老茶馆 / 乐山大佛 / 采耳 / 峨眉武术 / 熊猫  
- 邀请：慢下来，体会 *bashi* 生活——非成就清单

**蒸馏：** To Whom 可用**一个当地可感词或日常场景**；场景串要短，单帖只留 1 个主点。

### A5 UNESCO 茶（学：权威轻点）

要点：制茶技艺 + **待客/社交/仪式**日常实践；六大茶类；多民族共享。

**蒸馏：** 有 UNESCO/官方条目在 `evidence_used` 时，正文点到「日常分享的茶」即可，禁止堆「世界第一非遗」口号。

## 二、从语料蒸馏的帖文模式（写入主 skill）

1. **钩子必须具体**：时间/地点/反差/问句（A2/A3/A4），禁止「Culture speaks quietly」式空壳（列表站反例）。  
2. **Says What = 一个可感锚**：一座城、一道菜、一种茶、一趟夜行，而非「多元文化」。  
3. **感官优先于抽象赞美**：灯、水、味、声（A2）。  
4. **微型旅程弧**（中长 caption / thread）：出发动机 → 途中细节 → 一句人物或变化 → 轻收束。  
5. **ops_tips 外置**：票价、车次、开放时间不进故事主句，除非用户要攻略帖且证据有。  
6. **权威轻点**：UNESCO/机构名一笔带过，服务场景，不替代场景。  
7. **当地桥梁**：一词（如 *bashi*）或通勤/周末画面，服务 To Whom。  
8. **禁猎奇刻板**：饮食「什么都吃」类玩笑；禁抬杠他国。  
9. **短视频口播感**：好奇问句 → 一个事实/场景 → 轻邀请。  
10. **hashtag**：地点 + 主题；3–8 个；勿只有口号标签。

## 三、与项目硬约束的对齐

- 语料中的票价、时长、粉丝数、历史年代：**仅作结构参考**；成稿无 `evidence_used` 则删除。

## 四、操作细则（自主 skill 下沉 · 2026-09-18 lite）

主工序卡：`china-story-post.md`。需要时再读本节。

### 5W 可执行表

| 5W | 策划写什么 | 正文要看见 | 不合格 |
|----|------------|------------|--------|
| Who | 发声角色 | 语气匹配 identity | influencer 却通稿腔 |
| Says What | 一句可核验主点 | 围绕该点；能在 evidence 找到 | 空词「多元文化」 |
| Channel | 平台 | X 短；IG 可读；TikTok 钩子靠前 | IG 写成新华通讯 |
| To Whom | 目标国 | 一句当地可感 | 全球宣传腔 |
| Effect | 期望效果 | 轻提问/可分享 | 空赞口号 |

### 平台长度

| 平台 | 建议 |
|------|------|
| X | ≤280 字符；更长用 thread |
| 微博 | 80–140 汉字 |
| Facebook | 80–150 词 |
| Instagram | 60–120 词 + tag 3–8 |
| LinkedIn | 100–180 词 |
| TikTok 文案 | 口播短句；钩子靠前 |

### 变体

- thread：6–10 条；钩子→过程→收束提问  
- visual_story：4–8 页 slides  
- caption_only：压缩版钩子→锚→事实→收束  

### 缺省参数

platform=instagram · country=America · tone=optimistic · identity=online_influencer
