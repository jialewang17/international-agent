# 帖文 Skill（post）

**何时用**：海外社交帖 / thread / 图文 caption。  
**不用**：通稿、特稿、短视频分镜、FAQ 清单。  
**细则**：`china-story-post-reference.md`（勿整篇注入）。铁律：`intl-comm.md` + evidence。

## 步骤

1. 确认 platform / country / identity（缺省：instagram / America / online_influencer）
2. 写实 `five_w`（不可空壳）；正文必须能对照回 5W
3. 正文骨架：钩子场景 → 1 个感官/地点锚 → 1 个 evidence 事实 → 轻收束/提问
4. 按 format 填字段（见下）；攻略数字放 `ops_tips`，不进故事主句
5. 自检：无空壳诗句、无猎奇刻板、无抬杠、数字可追溯 evidence

## 输出字段

| format | 主字段 |
|--------|--------|
| social_post（默认） | `post` + `five_w` + `hashtags` + `platform`；可选 `alt_versions` / `ops_tips` |
| thread | `tweets[]`/`posts[]` + `five_w` + hook/cta |
| visual_story | `slides[]` + cover_line/cta |
| caption_only | `caption` + hashtags/alt_text/cta |

## 5W 一句话标准

| W | 必须能回答 |
|---|------------|
| Who | 发声角色与语气一致 |
| Says What | 一句可核验主点（有场景锚） |
| Channel | 平台长度与口吻匹配 |
| To Whom | 至少一句当地可感 |
| Effect | 可分享收束，非空赞口号 |

## 红线

- 证据没有的职务/金额/人次等 → 删  
- 禁：Culture speaks quietly 式空壳；饮食猎奇刻板；通稿腔；踩他国  
- 单帖只留 **一个** Says What
