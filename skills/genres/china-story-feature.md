# 讲好中国故事 · 深度报道 / 特稿体裁 Skill（feature）

**适用**：深度报道、专题稿、特稿、非虚构长文、longform / feature。  
**权威教材**：《南方周末写作课》（南方周末，z-library 扫描版；上篇「如何讲故事」）。  
**不适用**：社交帖文（5W 短 caption）、新闻通稿/新华体、短视频分镜。老师 0822：**南方周末长模板不适合作短帖**。  
**状态**：**可用**（方法已从教材蒸馏入库；评测集待补，尚未达到帖文/通稿的 40 组闭环）。

> 南周对特稿的概括：**追寻文字的美，呈现复杂的真。**  
> 生成时只调用**方法**（结构、场景、冲突、细节规则），**禁止复述/改写教材范文原文**（如《野马危急》《十二木卡姆》等下篇作品）。

## 权威边界

1. 老师 2026-08-22：深度稿独立体裁；南周骨架给中长深度，不给贴文。  
2. 证据：`intl-comm.md` + `evidence-user-materials.md`——事实/数字/专名/引语只能来自 `evidence_used`。教材亦强调：特稿**不容编造、夸张**，材料来自采访与调研。  
3. zip `longform` 字段壳：`headline` / `dek` / `body` / `pull_quote` / `suggested_visuals[]`。  
4. 细则附录：`china-story-feature-reference.md`（默认不整篇注入）。

## 一、动笔前（南香红：先理解再写）

成稿前必须能回答，写不进就停或列 `missing_fields`：

1. **为什么写这个故事？** 对海外读者的意义框架是什么？（普世锚，不是口号墙）  
2. **为什么是现在？** 有无激活点（材料里的变化/由头）；没有动态点则勿硬写「静态百科」。  
3. **故事五维度**是否清楚：时代 / 期限 / 地点 / 冲突（哪一层） / 人性（人际、内心或命运）。  
4. **一句话法则**（雷磊）：用**一句**说出故事主心骨；写不出来 = 结构未立，禁止开写。

材料不足时：**宁短、宁停，不编现场。** AI 不能补采访；只能用用户上传 ∪ 本地库。

---

## 二、成稿骨架（抽象阶梯 + 戏剧结构）

**抽象阶梯**（Roy Peter Clark，教材引用）：  
- 顶端 = 意义/定位（点到即止，禁止说教）  
- 底部 = 可感场景与精准细节（展示，不解释）  
- **禁止停在中部**：既无场景又无意义的「正确空话」

**结构**（可向戏剧三幕学，勿写成通稿电头）：

| 段 | 写什么 |
|----|--------|
| 开头（前三段必须抓住） | 一场可感场景或一个未解的具体问题；悬念来自材料，不来自煽情 |
| 展开 | 情节带动；显性冲突推进事件，隐性冲突指向更长久的主题（人与自然、文明交会、生计与土地等——须材料支撑） |
| 收束 | 回到开篇场或留下可回味的精准细节；可用循环/隐喻/克制总结；**禁止**帖文 CTA、emoji、Would you visit |

**场景三原则**（材料里有才能写）：真实性（细节 100% 可核验）· 生动性（气氛可感）· 现场性（有当下与动作）。间接、不精准的细节**放弃**。

**展示句**（教材金句，作规则不作文抄）：别讲给我听，请展示给我看。故事大师不解释意义。

## 三、与本项目其他体裁隔离

| | feature 特稿 | news 通稿 | post 帖文 |
|--|-------------|-----------|-----------|
| 骨架 | 场景→冲突→意义自现 | 地点反差→机制→数据→模式点到 | Lasswell 5W + caption |
| 人称 | 第三人称叙事；可有限跟一个人物 | 报道第三人称 | 常第一/第二人称 |
| 冲突 | 要有显性+隐性（材料允许时） | 不靠戏剧冲突 | 不靠长冲突弧 |
| 结尾 | 回味/循环/克制 | 模式可迁移 | CTA |
| 长度 | 材料够则 1500–3000 词（英）或相应中文；不够则缩短 | 450–900 词通讯或更短消息 | 平台字数 |

---

## 四、输出字段

- 必填：`genre: feature`；`headline`；`dek`；`body`；`one_liner`（一句话主心骨）；`five_dimensions`（时代/期限/地点/冲突/人性，各一句）；`evidence_used`  
- 可选：`pull_quote`；`suggested_visuals[]`；`missing_fields`；`caveats`  
- **不要**输出 `five_w`、hashtag 堆、emoji 作为主成品  
- 评测集未齐前可带 `genre_status: methods_in`（方法已入库，非「未写」占位）

---

## 五、成稿自检

1. 能否用一句话说清主心骨？不能 → 重结构。  
2. 前三段是否可感？是否通稿导语或 IG 钩子？串味则改。  
3. 每个场景细节能否映射 Evidence#？不能则删。  
4. 是否停在抽象阶梯中部（正确空话）？有则改成底部场景或删掉说教。  
5. 有无编造对话、精确钟点、未给出的职务/数字？有则删。  
6. 结尾是否口号墙或 visit CTA？有则改。
