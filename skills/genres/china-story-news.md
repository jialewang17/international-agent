# 通稿 Skill（news）

**何时用**：新闻通稿 / Across China 通讯 / 短消息 / press_kit / newsletter。  
**不用**：社交帖、特稿南周长弧、短视频分镜、GenZ 种草。  
**细则**：`china-story-news-reference.md`。铁律：`intl-comm.md` + evidence。

## 步骤

1. 按材料厚度选：短消息 vs 通讯（宁短勿编）
2. 骨架顺序（可合并）：地点反差 → 场景 → 具名人物（有证据才写）→ 时间转折 → 机制 → 权威句 → 数据 → 模式点到收束
3. 第三人称、冷静；无 emoji / Imagine / Would you visit / 5W 帖文腔
4. 每句事实映射 evidence；离题库条目不写进正文
5. 即使用户要求 IG/GenZ → **仍出通稿**

## 输出字段

| format | 主字段 |
|--------|--------|
| news_article | `headline` / `dek` / `article`；可选 pull_quote / suggested_visual |
| newsletter_brief | subject_line / preview_text / body / cta（通稿式） |
| press_kit | news_blurb / headline_pack / key_facts + 可选块；缺块写 `omitted_reason` |

篇幅参考：英 450–900 词通讯或更短消息；用户 `max_words` 优先。

## 红线

- 禁帖文 CTA/emoji；禁口号墙收束  
- 无证据不写姓名职务数据对话  
- 不为凑长而编机制
