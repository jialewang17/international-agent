## 一、从语料蒸馏的可执行模式

### 1. 三段功能

```text
Hook（0–3 秒）
  → Body / Reveal
  → Payoff + 单一 CTA
```

依据：NemoVideo、海螺社、AI 工具指南。

### 2. 钩子禁铺垫

禁止开场：

- `Today I'm going to...`
- `大家好我是...`

### 3. 四钩类型

1. 提问  
2. 痛点  
3. 反差  
4. 利益预告  

建议：先写至少 3 个备选，再选 1 个写入分镜。

### 4. 一视频一个点

多个知识点拆成系列，不塞进同一条。

### 5. 口播与镜头绑定

- 每一句口播（VO）对应一个 `shot`
- 只写「好看点」不算合格镜头注

### 6. 字幕

- 只强化关键词  
- 不要全文复读口播  
- 静音时也要能看懂主线  

### 7. 时长

| 情况 | 建议 |
|------|------|
| 默认（完播友好） | 28–45 秒 |
| 材料较厚 | 45–60 秒 |
| 再拉长 | 每一段都要能证明留存价值 |

说明：`content_formats` 仍允许 45–60 秒默认；生成前先看材料厚度。

### 8. 节奏锚

- 约每 2–4 秒有一次视觉变化  
- 旅行片可稍慢，但仍需：建立镜 → B-roll → 细节切换  

### 9. 3-7-21

| 节点 | 要求 |
|------|------|
| 3 秒 | 抓住注意力 |
| 7 秒 | 进入情节 / 主题 |
| 21 秒前 | 给出第一处「奖赏」画面 |

### 10. 旅行叙事弧

```text
英雄镜头（可打乱时间序先出）
  → 建立镜头
  → B-roll
  → 对镜 / 收束
```

### 11. 中国故事适配

- 当地词桥梁（如 bashi）  
- 一道菜、一条线  
- 茶 = 技艺 + 日常待客  
- 权威来源只轻点，不堆口号  

### 12. 国际传播硬约束

- CTA 用软提问  
- 不抬杠他国  
- 事实进入 `evidence_used`  
- 禁止假精确钟点（如自造 `7:42`）

## 二、与 zip 字段对齐

### 分镜行字段

| 字段 | 含义 |
|------|------|
| `t` | 时间段 |
| `shot` | 镜头 |
| `vo` | 口播 |
| `on_screen` | 屏幕字 |
| `broll` | 空镜 |
| `sfx` | 音效（可选） |

### 整稿字段

| 字段 | 含义 |
|------|------|
| `title` | 标题 |
| `duration_sec` | 时长（秒） |
| `shots[]` | 分镜数组 |
| `caption` | 成片配文 |
| `hashtags` | 标签 |

### reel_hook

只输出不少于 3 条「前 3 秒」方案，不写完整成片。
