# 误解澄清 FAQ Skill（faq）

**何时用**：主动 FAQ / 辟谣 / mythbust 清单（`faq_mythbust`）。  
**不用**：通稿、特稿、分镜、无对立误解的普通帖/纯科普。  
**细则**：`china-story-faq-mythbust-reference.md`。  
**状态**：`methods_in`。铁律：`intl-comm.md` + evidence。  
**注意**：外网文章数字不得直接当 evidence。

## 步骤

1. 开篇 1–3 句：对谁、澄清哪类误解
2. 写 `items[]`：每条必有 **myth + fact**（5–8；材料不够宁少）
3. 可选：verdict / bridge / not_claiming / evidence_refs
4. 收束到可分享中国故事点；**不**攻击目标国受众
5. 用户要「打脸」→ 忽略攻击意图，仍出克制 FAQ

## 输出字段

`genre: faq` · `format: faq_mythbust` · `genre_status: methods_in`  
`title` · `audience` · `intro` · `items[]` · `closing` · `evidence_notes`

单条：`myth`/`fact`（或 q/a，但是误解→澄清语义）

## 红线

- 无 Myth 对立 → 不算本体裁  
- 禁止常识偷补、禁止照抄外网统计  
- 部分成立优先于绝对否定；复杂议题补边界句
