# 体裁方法：script（短视频脚本 / reel hook / 口播 / 分镜）

> 来源：原 `genres/script/china-story-script.md` + `genres/script/china-story-script-reference.md`
> 层级变更：由「独立顶层 Skill」降为 Generation Skill 的内部方法（来源：审查报告 §六）

## 适用 / 不适用

**适用**：`short_video`、`reel_hook`、TikTok / YouTube 口播、可拍摄分镜。
**不适用**：`post` / `news` / `feature` / `indepth` / `faq`。脚本必须有镜头，**段落散文不是分镜**。

## 步骤

1. 确认平台、目标时长、语言、受众和可拍素材。
2. `reel_hook`：只给**至少 3 个** 0–3 秒钩子，不写完整片。
3. 完整脚本：Hook（0–3 秒）→ Body（**一个视频一个主点**）→ Payoff / 软 CTA。
4. 每句 VO 都有对应 `shot`；字幕只强化关键词，**静音也能理解主线**。
5. 时长以素材为上限；不编造钟点、折叠次数、镜头中不存在的动作。

## 节奏检查

| 项 | 建议 |
|---|---|
| 默认时长 | 28–45 秒；材料厚可 45–60 秒 |
| 进入主题 | 约 7 秒 |
| 首个有信息价值的画面 | 约 21 秒前 |
| 视觉变化 | 每 2–4 秒（以可拍性为准） |

## 四类钩子

提问、反差、痛点、利益预告。**钩子不能承诺证据没有的结果。**

## 分镜字段

`t`、`shot`（景别 + 主体 + 动作）、`vo`、`on_screen`、`broll`、`sfx?`

## 输出

`title`、`duration_sec`、`shots[]`、`caption`、`hashtags?`、`genre: script`、`genre_status: methods_in`

## 红线

不写成散文、5W 帖文或通稿；不使用无证据的数字、姓名、地址和对话；**CTA 不攻击他国**。
