# 生成内容评价维度文献库（LIT Dimension Bank）

**用途**：为「讲好中国故事」Agent 成稿评价提供可引用的学术维度与出处；**不替代** `UNIFIED_SCORECARD_v1.md`，而是为其提供命名与理论锚点。  
**更新**：2026-09-14（郭亚军、王佳淇、李坤、李蕾等 PDF 及文内参考文献）

---

## 0. 使用原则

1. **成稿质量 ≠ 平台体验**：内容/表达进 S·P·N；交互/系统质量仅用于评前端或产品，不并入成稿总分。  
2. **流畅 ≠ 可靠**（李坤）：语言通顺可作辅维，不得压过事实与证据。  
3. **fit for use**（Eppler & Wittig）：有/无用户上传资料采用不同达标线（与会议「双轨评价」一致）。  
4. **少而可操作**：答辩与工程以统一计分卡为准；本库作「可引用维度池」。

## 1. 核心文献的自带框架

### 1.1 郭亚军等《AIGC质量评估指标体系构建研究——以ChatGPT为例》

- 出处：《图书情报工作》2024, 68(22): 93-104. DOI: 10.13266/j.issn.0252-3116.2024.22.009  
- 方法：扎根理论 + 问卷 + AHP  
- 权重：内容 0.4547 ＞ 效用 0.2631 ＞ 表达 / 技术 各 0.1411  

| 一级 | 二级（文中含义摘要） |
|------|----------------------|
| 内容特征 | 多样性；可信性；新颖性；可追溯性；个性化；客观性 |
| 表达特征 | 易理解性；逻辑性；规范性；类人性；一致性 |
| 效用特征 | 时效性；传播性；有用性；可塑性；高效性 |
| 技术特征 | 简洁性；稳定性；主动性；安全性；可解释性；大模型算法；大算力；大数据 |

文中强调相对 PGC/UGC，AIGC 较特有的评估点：**可追溯、类人性、可塑性、可解释性**。

### 1.2 王佳淇《AIGC平台质量量表的开发与应用》

- 出处：山西财经大学硕士学位论文（平台质量 → 满意度 → 持续使用）  
- 理论：信息系统成功模型（ISSM）+ SOR  
- 四维构念：

| 一级 | 二级 |
|------|------|
| 内容质量 | 准确性、完整性、相关性、新颖性、可追溯性、客观性、有用性 |
| 交互质量 | 适应性、上下文理解、引导性、情境适应性 |
| 表达质量 | 一致性、易理解性、规范性、逻辑性、精确性、简洁性 |
| 系统质量 | 响应性、稳定性、安全性、可用性 |

实证提示：内容质量、交互质量对满意度有显著直接效应；满意度部分中介「平台质量→持续使用」。

### 1.3 李坤《生成式人工智能在档案自动化著录与内容摘要生成中的应用与质量评估》

- 出处：《山西档案》相关刊期文（档案场景）  
- **著录客观指标**：查全率、查准率、著录条目准确率、著录完成总时间  
- **摘要综合矩阵**：ROUGE（相对专家基准）+ 专家盲测（内容真实性、专业语言、上下文逻辑、多元信息处理）+ LLM-as-judge（准确一致性、逻辑连贯性）  
- 关键警示：大模型摘要常「形似神离」——浅层语言质量高，事实精度、核心完整度、学术语境规范不足。

### 1.4 李蕾等《社交媒体环境下学术型用户生成内容质量评估研究》

- 出处：《情报理论与实践》2023, 46(2): 175-183. DOI: 10.16353/j.cnki.1000-7490.2023.02.020  
- 对象：社交媒体上的 **学术型 UGC（AUGC）**（博客/论坛/微博/问答/学术社交网等）  
- 方法：用户实验访谈抽指标 → 问卷重要性 → **主成分分析**定权  
- 初始池：约 35 个指标，分四类（内容 / 来源 / 用户偏好与经验 / 社会化媒体环境）  
- 定稿模型：**4 个一级 + 11 个二级**（摘要写「两个一级」与正文表 8 不一致，以表 8 为准）

| 一级 | 二级（权重） | 解释要点 |
|------|--------------|----------|
| 与信息内容相关 | **演示性**（0.1124） | 展示清晰明了（权重最高） |
| | 合理性/一致性（0.1020） | 表达一致、符合逻辑 |
| | 事例性（0.1017） | 提供相关事例 |
| | 准确性/正确性（0.0655） | 准确无误、符合真实 |
| 与信息来源相关 | 可访问性（0.0969） | 信息可获取 |
| | 作者历史行为数据（0.0744） | 平台贡献频次等（社媒语境下的「权威代理」） |
| 与用户偏好和先前经验相关 | **有趣性**（0.1022） | 有吸引力、引起阅读兴趣 |
| | 适量性（0.0948） | 对用户是否适量 |
| 与社会化媒体环境相关 | 礼貌性（0.0877） | 无冒犯语言 |
| | 意见一致（0.0848） | 读者同意内容观点 |
| | 作者的经历（0.0776） | 提供作者相关经历 |

文中对比要点（对项目很有用）：

1. **传统学术出版**重期刊/作者权威；**AUGC** 难核验身份，常用「平台贡献行为」代理权威。  
2. 相对通识 UGC，AUGC 更重**演示性、有趣性、合理性**——科普/启发场景下，「讲清楚、愿意读、讲得通」权重大，不等于放弃准确。  
3. 话题领域会改变权重：健康类更重发布者权威与便利/有用；旅游类更重经验与准确；学术科普更重演示/趣味/合理。

与本项目帖文的直接启示：海外社交帖文接近「社媒上的知识/议题表达」，可把 **演示性→呈现清晰**、**有趣性→钩子/参与感**、**礼貌性→不冒犯受众**、**事例性→场景/证据具象** 写入帖文插件或人打档；**准确性**仍归共享层，权重工程上仍应高于「有趣」（与郭文「内容最重」一致，避免被社媒权重带偏）。

## 3. 会议五维 × 文献维度 × 统一计分卡

| 会议表述 | 文献可并入的维度 | 统一计分卡落点 |
|----------|------------------|----------------|
| 信息权威度（信源） | 可追溯、权威性、可信度、来源质量、客观性 | **S4** 可追溯；信源层级标注 |
| 证据支撑度（论据） | 准确性、完整性、深度、查准/查全、事实一致、FActScore | **S2** 越界；有料时 **S1/S6** |
| 本地化（语言） | 相关性、情境适应、易理解、受众匹配 | **P2** 受众桥梁；通稿 **N2** 口径 |
| 迷因 / 钩子 / 同款 / 参与感 | 传播性、可塑性、个性化、引导性；李蕾 **有趣性、演示性** | 帖文插件（建议 **人打**，机打为辅） |
| 意图隐形叙事（不生硬） | 类人性、逻辑性、规范性、专业表达、反口号；李蕾 **合理性/一致性、礼貌性** | **P1/N1** + 人工「口号感」档 |
| （帖文）具象可感 | 李蕾 **事例性**；郭/王 **易理解** | **P1** Says What 非空壳；场景句 |
| （双轨）有/无上传资料 | fit for use；覆盖/增益 | **S1/S6** 仅有资料场景启用 |
| （产品）前端体验 | 交互质量、系统质量 | **不计入**成稿 Shared/Plugin 总分 |

南周特稿方法（选题动机、接近真相、结构冲突、质感细节等）继续只挂 **feature** 插件，不硬套短帖。

## 4. 推荐采用的「精简学术表述」（答辩可用）

一句话：

> 本项目成稿评价以信息质量「适合使用」原则与 AIGC 内容/表达/效用框架为理论依据，工程上落实为共享层（证据可核验与资料关联）+ 体裁插件（帖文 5W / 通稿讲述口径）；平台交互与系统性能单独监测，避免与内容质量总分混淆。可操作的事实维借鉴原子事实支撑率思路；通稿形态对齐国内 AI 写稿质量评价规范中的主题准确、层次与流畅等要求。

对应权重直觉（与郭文一致，可写进说明，不必改工程满分结构）：

1. 内容/证据（最重）  
2. 效用/受众匹配与传播潜力  
3. 表达规范与体裁合度  
4. 技术/平台（产品侧）
