# 计分体系变更说明：旧三表 → 统一计分卡 v1

配套规范：`UNIFIED_SCORECARD_v1.md`

## 一句话

从「三套各说各话的 /30 分表」改为「**共享层评事实与资料关联 + 体裁插件评写得像不像帖文/通稿**」，并规定锚点专有性与机打/人工分列，方便后续人工验证。

## 主要差距

1. **结构**：旧=quality / news / materials_flex 分叉 → 新=Shared(S1–S6)+Post(P)/News(N) 插件。  
2. **资料能力**：旧=多在 flex 里测 → 新=S1/S2/S4/S6 升为所有成稿共享（有料时）。  
3. **提示遵从**：旧=一个大维易与覆盖双扣 → 新=硬约束归 S3，用料归 S1/S6，语气/讲述归插件或人工。  
4. **5W**：旧=贴文主维度且易被想成通稿也要用 → 新=仅帖文 P1。  
5. **通稿六维**：旧=独立六维（含证据）→ 新=证据进 S，插件只留讲述/口径/隔离三格。  
6. **增益测验**：旧=锚点可与 theme 撞车（MF03）→ 新=强制「theme 复述得不到」的专有锚点。  
7. **科学性**：旧=纯规则启发式当科学 → 新=承认工程量表 + 预留人工相关与分层报告。  
8. **汇报**：旧=易甩一个总分 → 新=必须分列 Shared 与 Plugin。

## 不变

证据硬边界、门控拒跑题、不嘲讽受众、无资料后专有锚点应下降的达标哲学、帖文 5W / 通稿反串味的产品立场。
