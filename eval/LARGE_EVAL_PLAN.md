## 4. 反馈自修正机制（建议本轮先做「离线闭环」）

```
跑测 → 打分 → 失败题打标签(D2编造/D7嘲讽/门控漏拦/…)
     → 写入「06_反馈自修正日志」
     → 提出「只改一处」的 patch 草案
     → 【问你】通过 / 修改 / 跳过
     → 通过后改 skill 或代码
     → 只重跑受影响题 + 回归 spot
     → 更新 05 对比表与 07 汇总
```

**在线自我修正（生成后自动 critique 再改稿）**：属于大功能，**需你单独批准**后再写代码。
